## 🚀 How to Use

### Adding Your First Income Entry
1. Click **"+ Add Transaction"** button in header
2. Select **"Income"** from Transaction Type dropdown
3. Choose income source (Part-time, Internship, etc.)
4. Enter amount in Rupees
5. Set date (defaults to today)
6. Click **"Add Transaction"**

### Recording an Expense
1. Click **"+ Add Transaction"** OR use "Income & Budget" → "Add New Expense"
2. Select **"Expense"** from Transaction Type
3. Choose category (Food, Rent, Transport, etc.)
4. Enter amount
5. Add optional description (e.g., "Weekly groceries")
6. Click **"Add Expense"**

### Setting Up Your Budget
1. Go to **"Income & Budget"** tab
2. Set spending limits for each category
3. Click **"Save Budget Settings"**
4. View "Budget vs Actual Spending" section
5. Monitor monthly adherence

### Creating a Savings Goal
1. Go to **"Savings Goals"** tab
2. Enter goal name (e.g., "Summer Vacation")
3. Set target amount in Rupees
4. Choose target date
5. Add optional description
6. Click **"Create Goal"**
7. Update progress monthly

### Viewing Your Financial Health
- Dashboard automatically calculates your **Financial Health Score**
- Score considers:
  - Income tracking (10 points)
  - Expense tracking (10 points)
  - Savings rate (15 points)
  - Budget adherence (10 points)
  - Goals progress (5 points)
- Personalized message explains your score

### Getting Insights
1. Go to **"Insights & Tips"** tab
2. Read AI-generated recommendations
3. Review student financial tips
4. Check FAQ for common questions
5. Use resources for learning

### Using Calculators
1. Go to **"Tools & Calculators"** tab
2. **Savings Calculator**: Enter monthly amount + months → See total
3. **Goal Timeline**: Enter goal amount + monthly savings → See months needed
4. **Net Income**: Enter income + expenses → See available funds
5. **Category Analyzer**: View breakdown of spending

## 💾 Data & Privacy

### How Your Data is Stored
- **Location**: Browser's LocalStorage (on your device only)
- **Encryption**: Basic (browser-level security)
- **Backup**: Automatic with each transaction
- **Sync**: No cloud sync (single device only)

### Data Your Dashboard Tracks
- Income entries and amounts
- Expense entries and categories
- Budget settings per category
- Savings goals and progress
- Dark mode preference
- All dates and descriptions

### Privacy & Security
✅ **No server transmission** - Data never leaves your device  
✅ **No account required** - Completely anonymous  
✅ **No tracking** - No analytics or cookies  
✅ **Local only** - Works entirely offline  
⚠️ **Browser dependent** - Data lost if browser storage is cleared  
⚠️ **Device specific** - Data doesn't sync across devices  

### Data Backup & Recovery
1. **Exporting Data**: No built-in export (data in LocalStorage)
2. **Manual Backup**: Open browser developer tools → Application → LocalStorage → Look for "financialData"
3. **Recovery**: If data is lost, sample data resets on next load
4. **Prevention**: Avoid clearing browser cache/data

**Change Theme**:
- Click the moon/sun icon in the header

**Customize Categories**:
The application comes with 7 expense categories. To add more:
1. Open the HTML file in a text editor
2. Find the category dropdown in the "Add Expense" section
3. Add new `<option value="category">Display Name</option>`
4. Also add the category to the budgets section
5. Save and refresh

**Adjust Budget Limits**:
1. Go to "Income & Budget" tab
2. Modify amounts per category
3. Click "Save Budget Settings"
4. Changes apply immediately

### Advanced Customization

**Modify Colors**:
1. Open HTML file in text editor
2. Find `:root { --primary: #6366f1; }` section
3. Change hex color codes
4. Save and refresh

**Change Currency**:
1. Find all `₹` symbols in the code
2. Replace with your currency symbol ($, €, £, etc.)
3. Note: Calculator formulas remain the same

**Adjust Financial Health Scoring**:
1. Locate `updateHealthScore()` function

## 🔧 Troubleshooting

### Common Issues & Solutions

**Issue**: "Data disappeared after closing browser"
- **Cause**: Browser storage was cleared
- **Solution**: Avoid clearing cache; use "Clear browsing data" carefully
- **Prevention**: Save important data elsewhere periodically

**Issue**: "Charts not showing"
- **Cause**: Add transactions first
- **Solution**: Charts need data; add at least 1 expense to see pie chart
- **Fix**: Refresh the page after adding data

**Issue**: "Can't see recent transactions"
- **Cause**: Transactions from current month don't exist
- **Solution**: Add transactions with today's date
- **Note**: Recent tab shows only this month's transactions

**Issue**: "Budget settings not saving"
- **Cause**: JavaScript disabled
- **Solution**: Enable JavaScript in browser settings
- **Check**: Open browser console (F12) for errors

**Issue**: "Can't print report"
- **Cause**: Pop-ups blocked
- **Solution**: Allow pop-ups for this site
- **Alternative**: Use Ctrl+P or Cmd+P for print dialog

**Issue**: "Negative net balance showing as positive"
- **Cause**: Display formatting
- **Solution**: This is correct; graph shows actual deficit
- **Action**: Review expenses and increase income if needed

### Browser-Specific Fixes

**Chrome/Edge Issues**:
- Clear cache: Settings → Privacy → Clear browsing data
- Disable extensions: Settings → Extensions
- Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)

**Firefox Issues**:
- Clear storage: Menu → Preferences → Privacy
- Disable add-ons: Menu → Add-ons
- Hard refresh: Ctrl+F5 (Windows) or Cmd+Shift+R (Mac)

**Safari Issues**:
- Clear storage: Develop → Empty Web Storage (enable Develop menu first)
- Disable extensions: Safari → Preferences → Extensions
- Hard refresh: Cmd+Shift+R

## 💡 Tips & Best Practices

### For Student Financial Success

**1. Track Everything**
- Record all income and expenses
- Even small purchases add up
- Consistency builds better insights
- Spend 5 minutes daily on entry

**2. Set Realistic Budgets**
- Base on your actual income
- Use the 50/30/20 rule as starting point:
  - 50% = Needs (rent, food, utilities)
  - 30% = Wants (entertainment, dining)
  - 20% = Savings & debt payment
- Adjust based on your situation

**3. Build an Emergency Fund**
- Target: ₹5,000-₹10,000
- For unexpected expenses (books, travel, medical)
- Keep in separate savings account
- Don't touch unless true emergency

**4. Monitor Spending Patterns**
- Review dashboard weekly
- Identify high-spending categories
- Look for unnecessary subscriptions
- Adjust habits proactively

**5. Automate Savings**
- Set up automatic transfer to savings account
- Even ₹1,000-2,000/month helps
- Treat savings like a non-negotiable bill
- Makes saving effortless

**6. Plan for Future Goals**
- Set 3-5 meaningful savings goals
- Make goals specific and measurable
- Set realistic timelines
- Celebrate milestones!

**7. Review Monthly**
- Spend 15 minutes analyzing dashboard
- Check health score and insights
- Review budget adherence
- Adjust categories if needed
- Plan next month

**8. Educate Yourself**
- Read finance tips in the app
- Learn about investment basics

### Habits for Success

## ❓ FAQ

**Q: Is my data secure?**
A: Yes, all data stays on your device. No transmission to servers. However, if someone accesses your computer/browser, they can see your data.

**Q: Can I use this on multiple devices?**
A: Not with data sync. Each device has separate storage. Download the file to each device separately.

**Q: What if I want to switch browsers?**
A: Your data won't transfer. Use browser export tools or manually note important information before switching.

**Q: How much data can I store?**
A: LocalStorage typically allows 5-10MB. For most students, this means thousands of transactions are safe.

**Q: Can I share this with friends?**
A: Yes! Everyone gets a private copy. Share the HTML file freely.

**Q: Does it work offline?**
A: Completely! No internet needed. Perfect for use anywhere.

**Q: Why does the health score change?**
A: It's based on your income, expenses, savings rate, budget adherence, and goals. Any transaction affects it.

**Q: Can I delete a specific transaction?**
A: Yes. In the Expenses tab, click "Delete" next to any transaction. Confirm the deletion.

**Q: What if I make a mistake?**
A: Delete the wrong entry and re-add the correct one. Changes happen immediately.

**Q: Can I edit an existing transaction?**
A: Currently, you delete and re-add. A future version might include edit functionality.

**Q: How do I print my report?**
A: Click "Print Report" button in header, or press Ctrl+P (Windows) or Cmd+P (Mac).

**Q: Is there a mobile app version?**
A: No, but the web version is fully responsive and works great on mobile browsers.

**Q: Can I use this with multiple people/family?**
A: Currently designed for individual use. Each person needs their own copy.

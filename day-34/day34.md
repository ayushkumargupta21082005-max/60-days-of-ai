## 🎯 Overview

Marketing Detective is an interactive educational game disguised as a detective mystery. Players examine real marketing campaign data, analyze clues, and identify the primary marketing mistake that caused underperformance.

Each case is based on realistic scenarios with:
- **Actual marketing metrics** (reach, CTR, engagement, conversions, sales)
- **Real customer feedback** (simulated reviews and comments)
- **Detailed clues** pointing toward the root cause
- **Expert explanations** of what went wrong
- **Actionable improvements** for future campaigns

This game teaches marketing strategy, campaign analysis, and decision-making through an engaging, gamified experience.

## 🎮 How to Play

### Step 1: Welcome Briefing
Read your detective briefing and accept a new marketing case assignment.

### Step 2: Case Assignment
Review the company profile, campaign details, and key metrics:
- Company name and industry
- Campaign objective and target audience
- Budget allocation and channels
- Quantified metrics (reach, CTR, conversions, sales)
- Customer feedback and complaints

### Step 3: Evidence Board
Drag and drop evidence clues onto your investigation board to build your theory. Arrange evidence to identify patterns.

### Step 4: Identify the Mistake
Answer the core question: **What is the PRIMARY marketing mistake?**
- Read three specific clues that point toward the problem
- Choose from multiple-choice options
- Submit your answer for evaluation

### Step 5: Case Closed
Receive instant feedback:
- ✓ **Correct**: You identified the real problem
- ✗ **Incorrect**: See what you missed

### Step 6: Learn the Lesson
Every case reveals:
- The actual problem and why it happened
- Specific improvements for future campaigns
- Real-world marketing principles

### Step 7: Performance Report
Track your progress:
- Accuracy percentage
- Common mistakes discovered
- Key learnings across all cases

## 🎨 Customization

### Change the Color Theme

The game uses CSS variables for easy theming. Edit the `:root` section:

```css
:root {
    --primary-green: #2d5016;      /* Primary green */
    --accent-green: #4a7c2e;       /* Accent green */
    --light-green: #7cb342;        /* Light green */
    --highlight-green: #a8d577;    /* Highlight green */
    --dark-bg: #0f1419;            /* Dark background */
    --card-bg: #1a1f2e;            /* Card background */
    --text-light: #e8e8e8;         /* Light text */
    --text-muted: #a0a0a0;         /* Muted text */
    --paper-cream: #f5f1e8;        /* Paper color */
    --cork-brown: #8b6f47;         /* Cork board color */
    --pin-red: #c41e3a;            /* Push pin red */
}
```

### Add New Cases

Add entries to the `marketingCases` array:

```javascript
{
    id: 21,
    company: "Your Company",
    industry: "Your Industry",
    objective: "Campaign objective",
    audience: "Target audience",
    channels: ["Channel 1", "Channel 2"],
    budget: "$XXX",
    metrics: {
        reach: "XXX",
        ctr: "X%",
        engagement: "XXX",
        conversions: "XXX",
        sales: "$XXX"
    },
    comments: ["Comment 1", "Comment 2"],
    socialPerf: "Social media description",
    mistake: "The primary mistake",
    clues: ["Clue 1", "Clue 2", "Clue 3"],
    explanation: "Detailed explanation",
    improvements: ["Improvement 1", "Improvement 2", "Improvement 3"]
}
```

### Modify Game Difficulty

Adjust the answer options by editing the `proceedToQuestion()` function to change how many correct/incorrect answers are shown.

## 🐛 Troubleshooting

### Game won't load
- Ensure you're using a modern browser (Chrome 90+, Firefox 88+, Safari 14+)
- Try a different browser
- Disable browser extensions that might block JavaScript

### Drag and drop not working
- Ensure JavaScript is enabled
- Try a different browser (some older browsers have limited drag-drop support)
- On mobile, long-press on evidence to drag it

### Buttons not responding
- Refresh the page
- Check browser console for JavaScript errors
- Try a different browser

### Performance issues
- Close unnecessary browser tabs
- Clear browser cache
- Try a different browser

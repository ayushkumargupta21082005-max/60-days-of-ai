## What is Prompt Puzzle?

**Prompt Puzzle** is an intelligent, gamified learning platform designed to help you master AI prompt engineering through hands-on practice. Instead of reading documentation, you'll solve real-world prompt challenges across 6 randomized expert-level scenarios.

Each scenario is grounded in authentic educational contexts—designing adaptive learning paths, implementing Socratic questioning, creating differentiated instruction—requiring you to understand both **pedagogy** and **prompt craftsmanship**.

### Why Expert Difficulty?

This version targets advanced learners who already understand:
- Bloom's taxonomy and cognitive demand levels
- Pedagogical frameworks (backward design, differentiation, metacognition)
- Assessment principles (formative vs. summative)
- Instructional scaffolding and learner variability

You'll encounter **nuanced, edge-case scenarios** where multiple approaches seem valid but only one reflects current best practices in educational technology.

## Challenge Types

### 1️⃣ Build the Prompt

**Goal**: Arrange prompt blocks in the correct sequence to create an effective instruction.

**How it works**:
- Left panel shows available blocks (correct + distractor blocks)
- Right panel is your drop zone
- Drag blocks to build your prompt sequence
- Distractors (red borders) lower your score if included

**Example Challenge**: 
*Adaptive Learning Path Design*
- Correct blocks: "Analyze mastery levels" → "Design progressive modules" → "Include formative checks" → "Provide adaptive scaffolding"
- Distractors: "Give all materials at once", "Use only summative tests", "Assume uniform pacing"

**Skills Tested**:
- Understanding instructional sequence
- Identifying pedagogically sound practices
- Filtering irrelevant information

---

### 2️⃣ Clean the Prompt

**Goal**: Transform a weak, vague prompt into a clear, expert-level instruction.

**How it works**:
- See the weak prompt in the left panel
- Rewrite it in the text area
- Reference the weak vs. optimized outputs for comparison
- Your version should be specific, structured, and actionable

**Example Challenge**:
*Socratic Questioning for Critical Thinking*
- **Weak**: "Ask students questions to help them think better"
- **Improved**: "Implement Socratic dialogue by sequencing questions through Bloom's taxonomy: comprehension → application/analysis → evaluation/synthesis, maintain 5-10 second wait times, respond to student answers with follow-up questions rather than validation."

**Skills Tested**:
- Specificity and clarity
- Structural organization
- Domain-specific vocabulary
- Actionability

---

### 3️⃣ Choose the Best Prompt

**Goal**: Evaluate four prompt options and select the one that best addresses the challenge.

**How it works**:
- Read the weak prompt
- Review four answer choices with descriptions
- Select the option that represents expert-level prompting
- Two options are tempting but ultimately flawed

**Example Challenge**:
*Differentiated Instruction*
- **Option A (Wrong)**: Simplify content for struggling students
- **Option B (Correct)**: Tiered cognitive demand for all students at their level
- **Option C (Wrong)**: Mix readiness groups randomly
- **Option D (Wrong)**: Separate students by ability and teach different content

**Skills Tested**:
- Distinguishing best practices from common mistakes
- Understanding nuanced educational concepts
- Evaluating pedagogical soundness

## Scoring System

### Real-Time Metrics

| Metric | Calculation | Impact |
|--------|-------------|--------|
| **Accuracy** | % of correct answers | Primary score component |
| **Time** | Seconds per scenario | Displayed for awareness |
| **Moves** | Number of actions taken | Reflects efficiency |
| **Wrong Placements** | Incorrect blocks placed | Penalty to final score |
| **Hints Used** | Number of hints requested | Influences optimization bonus |
| **Moves/Efficiency** | Actions vs. optimal path | Bonus points awarded |

### Scoring Formula

```
Final Score = (Accuracy × 10) + (Optimization Bonus × 0.5)
Optimization Bonus = 100 - (Wrong Placements × 5)
Accuracy = (Correct Answers / Total Scenarios) × 100
```

### Rank System

| Score Range | Rank | Rating |
|-------------|------|--------|
| 900+ | S+ | 🌟 Excellent |
| 800-899 | S | ⭐ Great |
| 700-799 | A+ | 👍 Good |
| 600-699 | A | 📈 Keep Learning |
| <600 | B | 📚 Learning |

### Bonus Points

- **Accuracy Bonus**: Points awarded for correct answers
- **Efficiency Bonus**: Points for completing with minimal wrong moves
- **Optimization Bonus**: Points for clean execution with minimal hints

## Educational Domains

### This Version: Education & Learning (Expert)

This game focuses on prompt engineering for educational contexts at the expert difficulty level. Scenarios include:

#### 1. Adaptive Learning Path Design
- **Concept**: Using AI to create personalized learning sequences
- **Challenge**: Specify mastery assessment, progressive complexity, formative checks, and adaptive scaffolding
- **Key Principle**: Expert prompts include learning mechanisms and feedback loops, not just content

#### 2. Socratic Questioning for Critical Thinking
- **Concept**: Using AI to generate strategic questioning sequences
- **Challenge**: Sequence questions by cognitive demand, include wait times, use follow-ups
- **Key Principle**: Pedagogical sequencing matters more than question quantity

#### 3. Differentiated Instruction Strategy
- **Concept**: Modifying instruction while maintaining rigor
- **Challenge**: Tier complexity without lowering cognitive demand
- **Key Principle**: True differentiation maintains cognitive demand across all tiers

#### 4. Learning Outcome Alignment
- **Concept**: Ensuring coherence between objectives, activities, and assessments
- **Challenge**: Implement backward design with cognitive alignment
- **Key Principle**: Use specific action verbs, not vague learning goals

#### 5. Metacognitive Strategy Development
- **Concept**: Teaching students to monitor and regulate their learning
- **Challenge**: Make thinking visible, teach explicitly, gradually release responsibility
- **Key Principle**: Metacognition requires explicit instruction and guided practice, not assumptions

#### 6. Assessment for Learning vs. Assessment of Learning
- **Concept**: Distinguishing formative (guides instruction) from summative (measures achievement)
- **Challenge**: Use formative throughout; summative at end
- **Key Principle**: These serve different purposes and aren't interchangeable

## Tips for Success

### Before You Start

1. **Understand the domain** — Familiarize yourself with educational terminology (Bloom's taxonomy, differentiation, scaffolding)
2. **Know the difficulty** — This is expert-level; it expects sophisticated understanding
3. **Read carefully** — Each scenario includes pedagogical nuance; read the desired output thoroughly

### During Gameplay

1. **Study the weak vs. optimized examples** — They reveal the exact pattern differences
2. **Use hints strategically** — Don't use them immediately; first try to solve independently
3. **Notice the prompt principle** — Each scenario teaches a specific lesson; understand it
4. **Think pedagogically** — Ask: "Does this reflect best practice in education?" not just "Does this work?"

### Specific Strategies by Challenge Type

#### For "Build the Prompt"
- Look for **action-oriented language** (verbs like "analyze," "design," "scaffold")
- Identify **logical sequence** (assessment before instruction, scaffolding before independence)
- Ignore blocks that sound good but aren't pedagogically sound

#### For "Clean the Prompt"
- Add **specificity** (from "better" to "faster, more engaged")
- Include **measurable criteria** (what success looks like)
- Use **structural language** (numbered steps, clear sequence)
- Reference **frameworks** (Bloom's, backward design, etc.)

#### For "Choose the Best Prompt"
- Eliminate **false dichotomies** (e.g., simplifying vs. challenging)
- Look for **nuanced understanding** (e.g., differentiation that doesn't lower rigor)
- Recognize **common misconceptions** as distractors (e.g., confusing formative/summative)

### Scoring Tips

- **Minimize wrong placements** — Each costs points
- **Complete efficiently** — Don't overthink; move forward
- **Use hints wisely** — Each hint slightly reduces bonus points
- **Consistency matters** — Accurate answers across all scenarios boost your rating

## FAQ

### Q: Do I need internet to play?
**A:** No. Prompt Puzzle is completely offline. Download once, play forever without internet.

### Q: Can I save my progress?
**A:** Scores are stored during your session. Close the browser to reset. Reload to start fresh with new scenarios.

### Q: What if I get stuck?
**A:** Use the 💡 Hint button (unlimited hints available). Each hint provides strategic guidance without giving away the answer.

### Q: Can I skip a scenario?
**A:** Yes. Click "⏭️ Skip" to move to the next scenario. Skipped scenarios count as incorrect.

### Q: How many scenarios are there?
**A:** 6 scenarios per game session. They're randomized from a pool, so replaying gives you different challenges.

### Q: What's the difference between "Weak" and "Optimized" prompts?
**A:** 
- **Weak**: Vague, non-specific, lacks structure, generic language
- **Optimized**: Specific, structured, includes pedagogical frameworks, actionable

### Q: Why is this Education & Learning focused?
**A:** This version teaches prompt engineering specifically for educational contexts. Domain-specific expertise requires understanding both prompt craft AND the domain (pedagogy).

### Q: What does "Expert" difficulty mean?
**A:** You'll encounter nuanced, edge-case scenarios where:
- Multiple answers seem plausible
- Small distinctions matter significantly
- Pedagogical understanding is essential
- Over-engineering is a common trap

### Q: How long does one game take?
**A:** 8-15 minutes depending on speed and thinking time.

### Q: Can I review my answers after finishing?
**A:** Not in this version. After finishing, you see your performance report and the optimized prompt. Replay with new scenarios to practice more.

### Q: What if I disagree with the answer?
**A:** This version reflects current best practices in educational technology and prompt engineering. If you have feedback, the principle explanation (💡) shows the reasoning. Consider replaying to deepen your understanding.

### Q: Can I print my performance report?
**A:** Yes. Use your browser's print function (Ctrl+P / Cmd+P) to save or print the results screen.

### Q: Does this help with other domains?
**A:** While this version focuses on education, the core prompt engineering principles transfer:
- Specificity and clarity
- Structural organization
- Context and constraints
- Testing and refinement

Consider practicing with other domains for comprehensive mastery.

### Q: Are there other difficulty levels?
**A:** This version is Expert difficulty. Other versions cover Beginner, Intermediate, and Advanced levels (not included in this release).

### Q: How do I know if I'm ready for expert?
**A:** You should understand:
- Bloom's taxonomy and cognitive levels
- Differentiation and scaffolding
- Formative vs. summative assessment
- Backward design
- Instructional frameworks

If these concepts are familiar, you're ready!

## 🔍 Understanding Your Statistics

### WPM (Words Per Minute)
- **Formula**: (Characters typed - Mistakes) / 5 / Minutes
- **What it means**: Your corrected typing speed
- **Goal**: Increase WPM while maintaining accuracy

### Raw WPM
- **Formula**: (Total characters) / 5 / Minutes
- **What it means**: Typing speed without error correction
- **Use case**: See uncorrected speed for reference

### CPM (Characters Per Minute)
- **Formula**: Total characters / Minutes
- **What it means**: Raw character input speed
- **Reference**: Used by some typing tests

### Accuracy
- **Formula**: (Correct characters / Total typed) × 100
- **What it means**: Percentage of correct keystrokes
- **Target**: Aim for 95%+ accuracy

### Consistency
- Shows variation in WPM across sessions
- Lower variation = more consistent
- Indicates typing reliability
- Improves with practice

## 🐛 Troubleshooting

### Application won't start
- Ensure JavaScript is enabled
- Try a different browser
- Check browser console for errors
- Clear browser cache
- Restart browser

### Stats not updating
- Click input field to ensure it's focused
- Check if typing is paused
- Verify JavaScript is enabled
- Reload the page

### Data not saving
- Check browser's local storage is enabled
- Ensure you're not in private/incognito mode
- Clear browser cache (will clear history)
- Try a different browser

### Font size not changing
- Use the slider in settings
- Values range from 12px to 32px
- Changes apply instantly
- Preference saves automatically

### Keyboard shortcuts not working
- Ensure focus is on the page
- Check that Ctrl key is being registered
- Try alternative browsers
- Some OS may intercept shortcuts

## 🎯 What is Media Integrity Analyzer?

**Media Integrity Analyzer** is an educational web application that teaches critical thinking about online content. It guides users through real-world scenarios to understand how headlines are manipulated, how emotional language influences perception, and how to become a more discerning media consumer.

Instead of teaching rules, it helps users *discover* manipulation techniques by analyzing realistic examples and thinking critically about what they see every day.

## ✨ Key Features

### Interactive Challenges

#### 🔍 Challenge 1: Headline Detective
- Analyze a realistic, exaggerated news headline
- Decide if you'd click and share it
- Identify misleading language
- Learn the Headline Accuracy Score
- See the fair, rewritten version
- Understand why sensationalism matters

**Example:** "SHOCKING: New Study Shows Coffee Will Give You Superpowers by 2025"

#### 😢 Challenge 2: Emotion Detector
- Analyze a social media post designed to manipulate
- Identify how it made you feel
- Highlight the emotional phrases used
- Learn about emotional hijacking tactics
- See how neutral framing changes perception
- Discover the psychology behind virality

**Example:** Posts using fear, outrage, and in-group language

### Real-Time Metrics Dashboard

Track your understanding across four dimensions:
- **Headline Accuracy**: Can you spot exaggeration?
- **Source Reliability**: Do you question origins?
- **Emotional Manipulation**: Do you recognize emotional tactics?
- **Audience Targeting**: Can you identify who benefits?

### Learning Dashboard

Upon completion, you receive:
- Overall Media Integrity Score
- What you learned (7 key insights)
- Biggest red flags identified
- Three practical habits for daily life
- Reset button to explore new scenarios

## 🧠 Learning Outcomes

After completing this tool, users will understand:

1. **Sensational Headlines** are designed to bypass critical thinking
2. **Emotional Language** is used to make you react before you think
3. **Real Information** doesn't need ALL-CAPS, extreme claims, or outrage
4. **Good Journalism** reports findings accurately without drama
5. **Your Feelings** are data—notice when content triggers strong emotions
6. **Curiosity** is the antidote to misinformation
7. **Sharing Matters**—pause before sharing content online

### Practical Habits Taught

**The Pause Before Share**
Before sharing any post or article:
- Read it completely
- Notice the language used
- Ask: "Is this informing or manipulating?"

**The Emotion Check**
When content triggers strong feelings:
- Anger, fear, or outrage = cue to investigate
- Ask: Am I reacting to facts or framing?
- Take a breath before sharing

**The Source Hunt**
Always trace content to its origin:
- Who created this?
- What's their incentive?
- What evidence do they provide?
- Do they cite their sources?

## 🚨 Red Flags Database

The tool teaches recognition of these manipulation techniques:

### Headline Red Flags
- Sensationalist words: "SHOCKING," "UNBELIEVABLE," "DEVASTATING"
- Exaggerated claims beyond study findings
- Artificial urgency ("by 2025," "ASAP")
- Quotation marks around paraphrased ideas
- Missing context or nuance

### Emotional Red Flags
- Fear-based language: "SECRET," "HIDDEN," "DANGEROUS"
- Us-vs-Them narratives: "Wake up!" "They don't want you to know"
- Moral outrage: "INFURIATING," "ABSOLUTELY DISGUSTING"
- Excessive punctuation and emojis (!!!, 😱, 🚨)
- Calls to immediate action: "SHARE NOW," "TELL EVERYONE"

### Source Red Flags
- No author attribution
- No publication date or outdated information
- No links to original sources
- Emotional tone instead of informative tone
- No opposing viewpoint mentioned

## 🤝 Contributing & Customization

### Easy Customizations

**Change the Theme**
Edit the `:root` variables in the CSS:
```css
:root {
    --primary: #FF6B35;           /* Change primary color */
    --primary-light: #FF8C5A;
    --primary-dark: #E55A2B;
    --bg-dark: #0F1419;           /* Change backgrounds */
    /* ... more colors ... */
}
```

**Update Scenarios**
Find these IDs in the HTML and edit the content:
- `#headline` - Change the sample headline
- `#socialPost` - Change the social media example
- Headlines in challenge analysis sections

**Modify Questions**
Change button text, question text, or add new questions in the question-group divs.

## 🐛 Troubleshooting

### Issue: Content not displaying
**Solution**: Make sure you're opening the `.html` file directly in a browser (not in a text editor)

### Issue: Animations not smooth
**Solution**: This is normal on older devices. The app works, just without animation polish.

### Issue: Mobile layout broken
**Solution**: All modern phones are supported. Check that zoom is set to 100%.

### Issue: Metrics not updating
**Solution**: Make sure JavaScript is enabled in your browser settings.
